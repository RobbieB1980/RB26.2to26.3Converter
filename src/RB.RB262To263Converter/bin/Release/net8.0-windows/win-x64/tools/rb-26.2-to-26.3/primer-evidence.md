# 26.2 → 26.3 evidence boundary

Primary references:

- Minecraft 26.2: https://www.minecraft.net/en-us/article/minecraft-java-edition-26-2
- Minecraft 26.3: https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3
- NeoForged primer: https://docs.neoforged.net/primer/docs/26.3/

The target versions differ in pack formats, number-provider registries, loot and
predicate references, block-state fields, noise settings, carvers, material
rules, renderer APIs, and the GLFW → SDL3 client backend. The preview therefore
automates only shape-preserving transformations. Renderer/client Java changes,
ambiguous worldgen rewrites, and dependency compatibility remain evidence-backed
repair work.
